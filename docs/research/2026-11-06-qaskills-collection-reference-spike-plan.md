# QA Skills 集合页参考调研与实施计划

> 状态：2026-11-06 已完成参考调研、原型确认、生产页面实施与本地验收。

## 目标

评估两个 QA Skills 集合页中能迁移到本站的发现与使用模式，并制作一个可交互、双语、响应式的独立原型，作为首页和详情页后续实现的视觉基线。

调研日期：2026-11-06。页面内容以当日实际浏览结果为准。

## 本站基线

- 首页源码：`src/pages/[lang]/qaskills/index.astro`。本地预览当时显示 162 个 Skills：148 个测试类型、10 个工作流、4 个 Plus。
- 首页已有双语搜索、主分类、扩展分类与生命周期筛选；常用入口已按用户此前选定的变体 2 呈现为目录式双栏列表。
- 详情页已有适用场景、输入、输出、工作原理、快速开始、相关推荐、原始 Skill 文档预览。示例核对页为 `test-case-writing`。
- 现有内容能支持任务匹配与输入/输出说明。目录没有经核验的安装量、实时趋势或统一质量分数据；页面也不应借用外站的统计或评级。

## Spike 结论

原型文件：[qaskills-collection-spike.html](../temporary/qaskills-collection-spike.html)

原型把两个值得验证的交互放在一个独立页面中：

1. **首页任务入口**：在现有分类目录前增加 3 个任务样例。切换任务会显示匹配 Skill、预计产出、路径阶段和下一步 Skill。
2. **详情产出预览**：沿用 `test-case-writing` 已发布的 Output 章节，展示输出字段结构，并标明这是结构示意，不是实际执行结果；同时呈现信息缺口和项目上下文边界。
3. **保留现有入口**：原型提供到本站目录、快速开始和详情的链接；完整搜索与筛选仍由现有目录负责。
4. **中英文和移动适配**：原型可以在中英文之间切换；窄屏下任务结果、详情和字段预览改为单列。

## 生产实施结果

- 首页增加三个双语任务入口，显示对应 Skill、预期产出、建议下一步和生命周期阶段。预期产出采用描述性短句，不把静态摘要写成已执行结果；原有搜索、筛选、双栏常用入口和完整目录保留。
- 详情页复用已有 Output 章节和字段预览，不重复建一份预览；新增预期产出边界说明，并为三条任务路径增加下一步 Skill 链接。
- 任务映射位于 `src/data/qaSkillTaskPaths.ts`，页面位于 `src/pages/[lang]/qaskills/`。中英文各三条下一步链接均已在浏览器中核对。
- 复核后调整：首页任务选项与常用入口、详情页下一步链接增加悬停/按压反馈，并在减少动态效果偏好下静止；切换任务仅播报当前任务和建议 Skill，避免屏幕阅读器重读整个结果面板。
- 上游同步：对照 `naodeng/awesome-qa-skills` 的 `main`（`17654bcf3f21d4a2df740d59a0b5fbb45ddc2524`），为本站增加 7 个中英文 Skill：`change-to-regression`、`one-page-test-strategy`、`pr-quality-review`、`requirement-to-test`、`skill-evaluation`、`skill-quality-review`、`tdd-quality-workflow`。仅带回新增页面和生成目录的 slug 更新，未重写已有 162 个 Skill 内容；目录现含 169 个 Skill。
- 验收：`npm run build` 通过，包含 Astro 检查、3309 个静态页面构建和 SEO 构建检查。ego-browser 手动检查任务切换、搜索态、详情提示和中英文路径；390px 手机宽度无横向溢出。桌面截图按 1440×1300 同视口对照原型与生产首页。
- 本轮未运行自动化 E2E；页面交互通过本地浏览器手动检查。

## 原定实施范围

### 首页

- 在搜索区与目录区之间增加轻量的“从任务开始”模块，保留现有常用入口双栏列表作为直接跳转方式。
- 首版只支持 3 个编辑维护的任务场景：需求分析 → 测试策略、测试用例编写 → 测试用例评审、缺陷上报 → 测试报告。每个场景必须映射到现存 slug，不做自动推荐或“AI 判断”。
- 每个结果呈现任务、推荐 Skill、一句话产出、可访问的下一步链接；点击仍进入现有详情页。
- 原型映射的推荐与下一步详情路径均已在本站中英文本地预览返回 200。
- 路径状态只说明“建议从哪个阶段开始”，不承诺自动编排或覆盖完整 QA 流程。
- 任务与 Skill 描述复用现有双语内容；预期产出短句在三条任务映射中显式维护，避免把完成式摘要读成已执行结果。

### 详情页

- 复用现有输出章节和字段预览；新增内容只补预期产出边界说明与相关下一步 Skill。
- 若没有真实样例，仅呈现字段结构并标注“结构示意”；不得伪造通过结果、缺陷、运行日志或评测数据。
- 让相关 Skill 显示为明确的下一步，例如“测试用例编写 → 测试用例评审”。保留详情现有相关推荐和工作流导航。
- 继续显示输入前提、事实/假设、信息缺口与执行边界；示例内容不能让用户误以为本站实际运行过该 Skill。

## 暂不迁移的功能

- Trending、Most Installed、下载量、质量分、Featured/HOT 排名：没有本站对应的可信来源和更新机制。
- Framework、Language、Domain 筛选：先核对并维护全量双语元数据，再评估价值；目前避免从简介文本猜标签。
- 复制外站的评测数字或安装/兼容性主张：即便展示历史数据，也必须注明本地评测来源、版本、任务、模型、指标与限制。
- 重复建设排序、过滤和完整分类导航：当前首页已有搜索、分类、生命周期和分类目录。

## 验收标准

- 用户能从一个具体任务看到对应 Skill、预期产出和可点击的下一步。
- 三条任务的推荐与下一步均指向真实存在的中英文 Skill 详情页；无虚构目录数量、排名、评测或执行结果。
- 首页新增入口不削弱现有搜索、分类筛选、双栏常用入口、完整目录和生命周期导航。
- 详情预览说明输出字段与来源，并区分真实示例、结构示意、缺失上下文和实际执行证据。
- 中英文内容可用；手机视口没有横向溢出、遮挡或不可操作的控件。
- 视觉对照通过后再交付生产实现；本计划和 spike 本身不算生产功能已完成。
