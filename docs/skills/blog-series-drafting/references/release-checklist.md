# 发布前检查清单

## 内容准确性

- [ ] 工具名拼写一致（标题、正文、文件名、README）
- [ ] 用户给出的链接都已读过
- [ ] 这些链接里的关键内链已继续检查过
- [ ] 关键能力点都有官方来源支撑
- [ ] 没有把推测写成事实
- [ ] 学习笔记中的关键观点、问题、限制与案例都能映射到正文
- [ ] 作者观点、研究结果、社区经验、编辑扩展和独立验证没有混为一谈
- [ ] 数字、因果关系和核验范围有来源支撑；不确定项明确标出

## 系列一致性

- [ ] 6 篇主题顺序完整
- [ ] 中英文各 6 篇，且一一对应
- [ ] 每篇都有导读/Overview、导航、参考资料
- [ ] 上一篇/下一篇链接正确
- [ ] 中英文版本的核心观点、示例和结论一致
- [ ] 中英文的事实、归因、限定、问题、来源顺序和链接目标一致
- [ ] H1、章节标题与目录不带数字序号，目录锚点都能跳转
- [ ] 正文外链及站内延伸链接显示名称和完整绝对 URL
- [ ] 参考资料里保留了真正用到的原始链接和关键内链
- [ ] 若使用 Mermaid 或其他图表，已核对实际呈现及移动端可读性
- [ ] 若使用图片，已核对来源/许可、替代文本、移动端显示与文件体积

## 可发布性

- [ ] Frontmatter 完整且符合 schema
- [ ] 标题与 description 可用于 SEO
- [ ] 日期遵守现有排期、跳过周末且每天不超过两篇；计划稿为 draft
- [ ] 语言风格统一，避免机械重复
- [ ] 每篇中文稿完成两轮 humanizer-zh 复核；每篇英文稿完成一轮 humanizer 复核，并核对自然度与双语一致性
- [ ] 若用户要求先 review 或确认修改范围，已按要求先报告发现再编辑

## 工程可用性

- [ ] 文件路径清晰且命名规范
- [ ] README 已列出完整系列
- [ ] 总目录（如 `docs/temporary/blog/README.md`）已登记新系列（如需要）
