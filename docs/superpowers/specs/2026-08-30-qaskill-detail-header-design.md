# QA Skill 详情页顶部重构设计

## 目标

将详情页顶部从松散的大留白卡片重构为紧凑的 Skill 摘要卡，让用户能在首屏理解 Skill 的用途、状态和安装入口。

## 选定方向

采用草图 A「产品摘要」。视觉方向为克制、信息密度高的产品说明卡，而不是安装控制台或纯文章标题条。

## 结构

1. 顶部标签行显示 Skill 类别和 Evals 状态，使用可读文字标签，不再使用无语义的图标。
2. 主标题下展示现有的 `intro` 摘要，限制为两行，避免过长文本撑高卡片。
3. 操作行保留“立即安装”主按钮和“源 SKILL.md”次按钮。
4. 底部信息栏显示作者和同步日期，并以细分隔线与主内容区分。

## 响应式与可访问性

- 桌面端保持内容左对齐、操作紧随摘要；不再通过绝对定位制造空白区域。
- 移动端自然折行，按钮可换行，元信息保持两端分布或在窄屏堆叠。
- 类别与 Evals 状态使用可见文本，屏幕阅读器不依赖悬停提示。

## 验证

- 更新现有详情页 E2E 断言，确认类别、Evals、摘要、作者、日期及两个操作入口可见。
- 运行相关 QA Skills E2E 和生产构建，检查桌面及移动布局不产生横向溢出。
