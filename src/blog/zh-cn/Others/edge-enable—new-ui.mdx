> **适用范围：**本文记录 2023 年 2 月的 Edge 实验性视觉效果设置，目标平台是 Windows 11，不适用于 macOS。Microsoft Edge 的实验项可能随版本和实验状态变化；若当前版本未显示该选项，这些步骤不适用。详见 [Microsoft Edge 配置与实验说明](https://learn.microsoft.com/en-us/deployedge/edge-configuration-and-experiments)。

- 打开 edge 浏览器
- 在地址栏输入命令
  `edge://flags/`
- 在 flags 的页面输入 11 进行搜索
- 在搜索结果下选择“Show Windows 11 visual effects in title bar and toolbar”将状态变更为启用

- 重启浏览器，即可看到新的 edge 浏览器 UI
