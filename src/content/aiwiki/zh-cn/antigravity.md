# Antigravity（反重力）（Antigravity）

> 一句话定义：Google Antigravity 是一款面向编码工作流的 Agent 优先开发平台。

## 科普速读

- **它是什么：** Antigravity 是 Google 推出的 Agent 优先开发平台。
- **适合什么场景：** 了解其当前的编码与 Agent 工作流功能。
- **主要边界：** 产品功能和开放范围会变化，应查看最新文档。

## 概览

Google Antigravity 是一款 Agent 优先的开发平台。Google 描述了让 Agent 在编辑器、终端和浏览器中工作的流程。具体功能和可用性会变化，应查看当前文档。

## 核心定义

Antigravity 是 Google 开发的 Agent 编码平台。Google 公布的工作流包括编辑器视图和用于协调 Agent 任务的管理界面。Agent 可以使用工具查看代码、修改文件并报告结果。

这个平台不是新的 AI 架构或协议，而是把模型、工具和产品工作流组合起来。各部分都有自己的限制和权限。

## 背景与发展

Google 于 2025 年 11 月发布 Antigravity，将其定位为 Agent 优先的开发平台。Google 在 2026 年又发布了 Antigravity 的新能力。本文解释产品类型，不提供一份固定的功能清单。

产品名称、模型访问方式和可用性会变化。选型前应查看 Google 的最新发布说明。

## 工作机制（How It Works）

1. 开发者向 Agent 提供任务和相关上下文。
2. Agent 使用平台启用的工具。
3. 根据任务需要，它可以查看或修改代码，并与终端或浏览器交互。
4. 平台可以提供计划、截图或其他制品供人检查。
5. 开发者检查差异、证据和测试结果。

可用工具和评审步骤取决于当前设置。制品本身不能证明改动有效。

## 在软件测试与开发中的应用

- **功能开发：** 让 Agent 完成范围明确的改动，并展示差异。
- **浏览器检查：** 让 Agent 打开本地页面并报告可见行为。
- **缺陷调查：** 提供失败报告，并要求 Agent 根据证据提出假设。
- **测试辅助：** 让 Agent 在获准环境中提出或运行测试。

合并或部署前，应评审代码并确认测试结果。

## 优势与局限

### 优势

- Agent 可以在同一工作流中搜索代码、修改文件并使用工具。
- 制品可以让部分中间结果更容易检查。
- 开发者可以委派范围明确的工作，并评审结果。

### 局限与风险

- Agent 可能误解任务，也可能拿到不完整的上下文。
- 工具操作可能修改文件或访问外部系统。
- 长任务会消耗更多时间和模型资源。
- 产品功能和可用性可能变化。

## 与相近术语对比

| 术语 | 主要区别 |

| Antigravity | Google 的一款具体开发产品 |
| AI 编码编辑器 | 集成 AI 辅助能力的编辑器类别 |
| Agent 工作流 | Agent 规划、执行并检查结果的一般模式 |

产品可以实现 Agent 工作流，但两者不是同一个概念。

## 实施建议（Best Practices）

- 一次交给 Agent 一个范围明确、完成条件可观察的任务。
- 开始高影响任务前，先检查计划和工具权限。
- 产品支持时，在独立分支或工作区中开展修改。
- 检查所有修改文件，并自行运行相关测试。
- 连接私有代码库前，查看当前产品设置和数据条款。

## 常见误区（Pitfalls）

不要把计划、截图或命令成功运行当成正确性证明。应检查改动代码，并在目标环境中确认结果。

## FAQ

### Antigravity 是否为所有任务使用同一个模型？

不要根据产品名称推断实际模型。可选模型取决于当前产品设置和可用性。

### 产品制品能否替代代码评审和测试？

不能。制品可以帮助人检查工作，但不能替代差异评审或测试。
